# 08 前端实施方案

> 基线 web2 `2215a75`。沿用 React/TypeScript、AntD、i18next、现有路由、Redux 和 request.ts；不新建全局 store、不重写构建链。具体版本以锁文件为准。

## 1. 页面与路由

所有路径拼接 UrlPrefix（现有 /v2），下表不是直接裸路径。原 /problem 和 /problem/:ProblemCode、IDE、题单地址继续可用；新增统一中心不抢原动态路由。

| # | 页面 | 路径/位置 | 访问边界 |
| --- | --- | --- | --- |
| 1 | 用户端口 | /account/assistant/ports | 登录 USER，本人；不强塞 ADMIN 布局 |
| 2 | 统一题目中心 | /problem-library | 公开/我的组/我的，超管全部；匿名读取需精确 AUTH 例外 |
| 3 | 统一题目详情 | /problem-library/:uid | 公开 learner 与 author 分投影，原编程题链接保留 |
| 4 | 九阶段出题工作台 | /manage/authoring/:id | 当前资源管理/协作权限 |
| 5 | 文档对照导入 | /manage/authoring/:id/import | 源文件与包权限，不直接发布 |
| 6 | 人类实测 | /trial/:linkId#token=... | 独立能力会话，不经 OJ 登录或 ADMIN 导航 |
| 7 | 查重扫描列表 | /manage/problemSet/plagiarism | 原场次管理权限 |
| 8 | 查重扫描详情/配对 | /manage/problemSet/plagiarism/:scanId | scan/scope/source 授权 |
| 9 | 绑定发布 | 扫描详情内 tab | 独立发布确认；默认不向学生展示 |
| 10 | 学生自查卡片 | 原题单/比赛详情内 | 本人+已发布 revision，只取专用投影 |
| 11 | 考务准备 | /manage/exam/prep | 原 exam/TEST/FORMAL 门禁 |
| 12 | 监考端 | /invigilate/:linkId#token=... | 独立轻量布局、能力会话和 room scope |

routerC 注册学生/本人页，routerM 注册管理页，router.tsx 的既有重定向保持兼容；能力路由单独定义最小布局与边界。新增 route ID 需全局去重，精确匹配并检查与动态路由排序。devOnly 是发布开关，不是后端鉴权；不因新页面完成就一次性移除所有 devOnly。

AIRouteBoundary 当前检查 AI 账户状态，不等于题目/考试对象权限，也不是独立能力会话边界。确定性题库/查重/材料功能不应被“没有 AI provider”挡住；端口修复与账户页在允许的封禁策略下仍应可访问，不随意放宽后台角色。

## 2. API 与状态约定

路径以 [07](07-API清单.md) 为唯一来源；前端不内联 URL，DTO 中 Long ID 用字符串。用既有 request 封装处理 message/旧 msg，页级只补业务上下文，避免同一错误重复 toast+Alert。

新增客户端模块按端口、题库/authoring、查重和监考拆分，不复制认证逻辑。能力会话也用受控客户端封装，但 401 进入邀请/过期界面，不触发 OJ 登录或清掉用户的 SESSION。浏览器同域 Cookie 可能共存，服务端严格按通道选择凭证，不能声称 withCredentials=false 就会自动只过滤 OJ Cookie。

- 成功写入后按服务端版本刷新，不猜测乐观成功；POST 带 operation_key/expected_version，同次重复点击复用 key。
- 切题、切账号、切场次或卸载使旧请求失效；ABA 往返不能让旧动作继续执行。取消请求不表示服务端副作用已撤销。
- 服务端分页显式使用 current/pageSize/total 或 cursor；AntD Table 不存在通用 pagination.serverSide 开关。
- 作业复用 2s 轮询，终态停；监考 15s、页面隐藏暂停、失败指数退避并保留 stale。取消/unknown/blocked/unsettled 有不同界面和恢复动作。
- 产物链接授权后下载；源文档、代码和姓名都按文本渲染，不使用未经净化的 HTML。文件名/CSV 不信任用户输入。

## 3. 关键交互

### 3.1 用户 AI 端口

列表显示名称、用户填写的模型、active 默认、当前额度/排队与有限探测状态。无默认时给配置引导，不自动选站点或首个备用。

新建/编辑 Modal 使用 password 输入但不回显原 key，显示“已配置/指纹 <digest>”；留空不变，改 endpoint 必须换 key，理由与版本冲突明确。不能把哈希摘要伪装成密钥尾号。公开文案不写未经核实的模型型号或“连接成功=支持全部 Responses 能力”。

设默认确认影响端口，禁用/删除提示在途任务和待对账；探测若会调用模型先确认费用。月预算零代表不限需显式确认。状态分别显示未探测、仅可达、能力未知、可用、无效、被禁用，不把 /models 404 一律视作不可用。

### 3.2 统一题目中心与详情

三 tab + 超管全部，支持 kind/tag/difficulty/keyword 与分页。source 是筛选，不是权限凭证；不存在或无权对象按服务端策略呈现。公开列表空态、搜索无结果、回源不可用分别显示。

题目卡片显示字符串 kind、公开/组内/私有和来源。管理者详情可有答案/数据操作；学生端不预取 author DTO 再隐藏字段。公开引用不显示编辑按钮，管理组编辑权保留原语义。前端不得把 obj:45/subj:45 或 position 当同一 ID。

### 3.3 九阶段与终检

阶段进度、当前编辑区、固定版本/manifest、AI 草稿与人工定稿清楚区分。进入下一阶段由服务端门禁判定；失效报告标“针对旧版本”，不保留绿色通过假象。

七项自动检查与独立人类实测分开展示，通过/失败/未运行/不适用带证据和批准理由。发布按钮使用 AntD `danger` 属性与确认（不是无效 type=danger），列出目标、版本、权限、文件清单及可能写入；partial/unknown 提供对账入口，不能给通用重试。

人类实测分别显示冻结题包版本、邀请 version、有效期和剩余作答次数；v1 每人一邀请、一次兑换，已兑换会话可重入。管理视图列出邀请及单独撤销入口；兑换结果丢失先查当前会话，无会话且已消耗时提示联系管理者撤销重发。服务端计时，按题型展示代码/选项/文本。反馈和得分记录绑定快照；不拿当前包内容替换试做副本。

### 3.4 文档、图片与翻译

双栏：左原页/图片，右可编辑题块。若引入 pdf.js 等新依赖，先核对当前依赖与原资产策略，不把候选库当已存在实现。页码/bbox 坐标系、源 hash、块版本和置信度未知状态都展示；低置信度与歧义需要人工核对。

原文/译文/双语切换不覆盖原文；术语表和来源版本可见，旧译文过期。导入仅建草稿，明确选择题型/题组；发布另行确认。

### 3.5 查重

管理视图：范围/时间截点、语言分片、已覆盖/失败/跳过、capture_metric/floor、review_metric/threshold、pair 表、矩阵和并排代码。显示 AVG 采集/MAX 复查差异及 legacy 不完整状态，不把跨指标阈值当同一数轴。矩阵只在同题同语言分片内；大样本聚合，不构造全场巨大二维 DOM。

阈值 1 明示跳过。阈值最多四位十进制小数，百分数输入须无损转换为 [0,1] 字符串，超精度明确拒绝。超出指标覆盖范围或低于同指标 capture_floor 时展示“需新扫描”；精确判定由服务端原始数值执行，70% 展示不等于严格等号。调整管理筛选不自动改变学生发布版本。人工决定必填理由、展示改判历史/冲突；AI 说明参考性质，不显示“已判抄袭”。

绑定单独确认显示范围与发布修订，初始 visible/show_code 关闭。学生只取本人专用投影，默认不请求 other_code；无绑定不渲染卡片。无记录文案只限定于本次发布范围，不把 partial/unknown 说成“无异常”。

### 3.6 考务与材料

主线：名单校验→持久账号台账→导入/对账→考场座位→渲染回验→发布材料→链接。每一步显示当前 roster/seat/account/material revision，允许从未知/失败位置恢复，不用重新生成密码。

密码默认不获取；保密导出/重印另确认并审计。部分导入、已存在账号、unknown 与重名有逐行状态，禁止“全部重试”覆盖既有账号。材料展示脱敏预览和五项校验；校验失败下载按钮不可用，不能靠前端跳过服务端门禁。

### 3.7 移动监考

375px 真机、单列卡片、触控≥44px、正文≥14px，安全区适配。固定考试/考场/刷新时间，异常/未观察到登录/未交卷分段筛选。无横向滚动；长姓名/考场换行，弱网保留旧值并标 stale/unknown。

fragment secret 兑换后立即从地址栏移除，不入埋点/localStorage/错误日志；会话由 HttpOnly Cookie 管理。页面不加载第三方分析/管理导航，不回传密码或学生代码。过期/撤销回到邀请失效页。

操作底部面板含对象、类型、备注与幂等状态；“登记补时”明确只是申请，正式加时由授权管理者另处理。自报监考姓名不能显示成已实名认证。

## 4. 双语、测试与发布

文案在 zh/en 同步新增，复用现有 locale 检查；业务状态优先用既有 key。不要通过修改全局 request 错误规则解决某个页面的预期失败。

| 范围 | 必须验证 |
| --- | --- |
| API/组件 | 空态、未知、错误、版本冲突、重复操作、取消和 stale response |
| 路由 | USER/管理者/超管/匿名能力隔离，旧编程题/IDE/题单/跳转参数保留 |
| 安全 | 后端字段已裁剪，直达 URL、跨 uid/场次/房间、过期/撤销/CSRF、恶意代码文本 |
| 浏览器 | Chromium/Firefox/WebKit，390–1440px；监考 375px 真机与断网恢复 |
| 真实服务 | 当前最终制品连真实 DB/Redis/MQ/Gateway/WebSocket；mock 不能替代鉴权/行锁验收 |
| 旧业务 | 登录、正式提交、云保存、Run、次数限制、原题型作答/评分与 TEST/FORMAL |

API 客户端与关闭状态的路由骨架可先行；具体页面随领域接口与权限一起验收，按开关逐项放行。匿名入口、混合题组、自动 MCP 写能力不跟随统一菜单上线。前端和后端均记录回退版本与受支持数据格式。
