2026-10-19。承接 [35](35-S4-01统一检索投影提案.md)。本轮只实现 AutoLab 的元数据投影、受限列表/详情读取和隔离 SQLite 回归；没有同步生产数据、开放匿名入口、修改 Java 源表或 push。

## 实现边界

AutoLab `618e849`、`7c4a495` 新增 `oj_unified_problem` ORM/DDL、`upsert_batch`、有界 `sync_pages`、`rebuild`、tombstone 和闭合投影读取。三类身份固定为 `prog:<id>`、`obj:<id>`、`subj:<id>`；`kind/ref_id` 唯一，跨类型同号不合并。批次拒绝重复 native reference，重建只对同一 `source_system` 的缺失对象打 tombstone；分页源任一页失败时不会执行 tombstone。

新增只读入口：

- `GET /auto-task/ai/library/problems`：按 `source/kind/keyword/cursor/limit` 读取有界元数据；
- `GET /auto-task/ai/library/problems/{uid}`：learner/author 投影；

每次读取都按当前主体、公开状态、属主和管理组过滤；撤权对象统一按 404 处理，避免泄露标题或属主。返回不含答案、评测配置、测试数据或原始 payload。
