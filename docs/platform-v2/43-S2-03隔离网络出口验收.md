## 实际网络

测试提交 `7598a52`：`test_port_egress_network.py` 使用已存在 `python:3.9-slim-bullseye`，仅创建随机命名的 internal Docker bridge、DNS/HTTPS/proxy 服务和客户端。合成公网编号只在该 internal bridge 内分配，无 host port 发布，不连接该编号的真实外网服务。容器只读、去除额外 capability；服务只加绑定低端口能力。无 Dockerfile、镜像构建、拉取或原 dev 容器修改。

客户端执行原 production `port_egress.py` 的真实一请求子进程；私有 stdin 传合成 key，DNS/socket/TLS/urllib3 未替换。自有 CA 只装进该客户端容器默认信任路径，TLS/SNI/hostname 校验保持开启，错误主机名实测拒绝。当前已安装的纯 Python urllib3 以临时目录副本只读挂载；初次 Docker Desktop 无法挂载 host `/opt`，在网络业务断言之前失败，不计作产品 red。没有新增依赖或产品 fallback。

最终 **1 个 opt-in 实验、21 项边界检查全部通过**，10.98 秒；Python 3.9.23、urllib3 1.26.14、Linux arm64。镜像 ID 和原源码 SHA256 在 `s2-03-network-mounted-result.json`。

- 合法 HTTPS 保留原 Host/SNI 和 Authorization；真实 server 记录 10 次预期 HTTP，凭据匹配只存布尔值。
- DNS 首次返回本网络公网地址，原请求成功；第二次实际 DNS 回答 loopback。服务记录仅原数字地址连接，证明后续地址变化未改写该次连接；混合公网 A 与 loopback AAAA 在连接前拒绝。
- 实际解析下的 loopback、metadata、十进制/十六进制/八进制地址、IPv6 loopback、IPv4-mapped、6to4 均拒绝。
- 设定 HTTPS_PROXY/ALL_PROXY 且 NO_PROXY 为空，代理陷阱仍 0 请求；302 不跟随私网 Location；错误 TLS hostname、2000001 字节、压缩和畸形 JSON 均拒绝。结果与 stderr 不包含合成 key 或 provider 诊断。
- models 正常只返回目录数量2，无模型 ID；models 404 返回 supported/not_observed/null，不制造 Responses 结论。
- 真实慢响应与慢 DNS 分别由子进程自身 SIGALRM 在 1.167/1.184 秒终止，无父 worker watchdog；随后健康原请求成功。父租约/取消属于已有单独范围，此实验不冒充完整 worker/SDK/profile 验收。

finally 实际删除两个容器与自有 network，cleanup_errors 为空；再次清点同名前缀，无遗留对象。未使用真实用户 key 或对真实端口重复探测。
