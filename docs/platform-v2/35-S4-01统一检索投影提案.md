# S4-01 统一检索投影提案

2026-10-19。本文只冻结实现边界和验收合同，不执行 DDL、AUTH 放行或生产同步。对应任务为 `S4-01`，门禁为 `SCHEMA` 与 `AUTH`。

## 目标

在 AutoLab 建立三题型的只读检索投影，供后续 `/library/problems` 使用。投影用于有界检索和变更检测；Java/Autolab 原表仍是权威来源，投影不授予题面、答案、测试数据或编辑权限。

统一身份固定为：

- `prog:<decimal problemId>`：Java 编程题；
- `obj:<decimal pid>`：Autolab 客观题；
- `subj:<decimal pid>`：Autolab 主观题。

`obj:45` 与 `subj:45` 永远是两个对象。重复题单引用使用独立的 `scope_item_key`，不能因 `uid` 相同合并显示或覆盖顺序。

## 源读取合同

### Java 编程题

复用现有 `ProblemManageService.queryProblemByPage` 和 `queryByCode` 的管理/公开谓词。新增适配只允许传入固定的页大小、游标和检索条件；不能接受任意 SQL、URL 或 problemCode 之外的路由。批量结果至少返回 `problemId`、`problemCode`、标题、属主、公开标志、管理组集合、标签/难度摘要和源版本摘要。详情或答案仍回源原 Java 接口，并重新校验当前主体。

### Autolab 客观/主观题

复用原题目和题组模型的类型、`pid`、创建者和题组成员关系。批量读取按 `(kind, pid)` 返回题目标题和检索元数据；题组成员只作为待校验引用，不把题组 JSON 直接当成 ACL。每条返回必须同时带 `kind` 和原生 `pid`，缺失类型、孤儿引用或来源读取异常进入失败清单。

## 投影字段和同步语义

首期只写 `uid/kind/ref_id/source_system/title/owner_id/owner_username/visibility/manager_group_ids/tags/difficulty/source_signature/tombstoned/synced_at`。不写答案、评测配置、测试数据、学生答卷、密钥或原始错误正文。

`source_signature` 对规范化的来源类型、主键、标题、属主、公开标志、管理组集合、标签/难度及删除状态计算。来源字段变化先更新签名，再由下一次回源权限检查决定是否允许返回详情。删除或无法确认来源时只保留 `uid`、`tombstoned=true` 和时间戳；对普通检索直接隐藏，不能通过旧索引泄露标题。

同步使用稳定 `(kind, ref_id)` 顺序和不透明 cursor。每页有上限，过滤掉无权限/已删除对象后仍返回准确 `has_more`，不暴露扫描总量。重建按同一顺序从头生成临时批次，批次摘要与源计数/签名清单一致后再切换；中途失败保留旧投影并记录 partial，不把部分索引当成完整结果。

## 权限和失败矩阵

| 场景 | 列表 | 详情 | 投影动作 |
| --- | --- | --- | --- |
| 公开且源校验成功 | 返回 learner 元数据 | 只返回 learner | 不给 author 权限 |
| 组内/私有且主体无当前源权限 | 省略或按统一 404 策略 | 404 | 不泄露标题/属主 |
| 索引存在但源回源失败 | 不返回该条，记录校验失败 | 503/统一 404 | 不把旧 ACL 当授权 |
| `kind`/`ref_id` 不匹配或重复冲突 | 拒绝该批次 | 不返回 | 保留冲突证据，不覆盖已有行 |
| 同一题在多个题单 slot 出现 | 各 slot 独立投影 | 按当前 scope 返回 | 不按 uid 去重 slot |

统一入口只接受已经批准的主体和 `source` 范围；`source=all` 仍需原超管语义。任何新增匿名公开入口、跨服务授权或现有题组 ACL 变化另行走 AUTH 门禁。

## 验收出口

1. 合成三题型批量读取：同号跨类型、重复 slot、长整数和 cursor 翻页均保持精度与顺序。
2. 撤权、删除、来源签名变化和同步中断：旧索引不再返回标题/答案；重建失败不替换旧投影。
3. Java 与 Autolab 各一组正/负/恢复用例：当前合法主体可读，撤权后拒绝，恢复后只按新签名恢复；不直连另一数据库。
4. 记录 batch hash、源计数、失败项和切换时间；所有字段闭合，测试确认没有原始 payload 或 provider/凭据字段。

## 需要的批准

批准后才进入实现：

- `SCHEMA`：创建/变更 `oj_unified_problem` 及其重建索引所需的最小 DDL，并在隔离 MySQL 验证唯一键、`kind` 检查和 tombstone 语义；
- `AUTH`：允许 AutoLab 以当前 Java/Autolab 会话执行上述有界批量回源校验，并确定公开 learner 入口的精确白名单。

在两项批准前，保持 `/library/problems` 关闭，不新增匿名路径，不把现有表复制到 AutoLab。
