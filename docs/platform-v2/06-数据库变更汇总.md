# 06 数据库变更汇总

> 全部 DDL 汇总。共 **7 张新表 + 5 处改表**。新增列一律 `NULL` 或带默认值，保证不中断现网。
>
> 库归属：`auto_*` 在 **Autolab 库**（`sduoj_ext_problem_set`），`oj_*` 新表中凡涉及原生数据者亦在 Autolab 库；`oj_unified_problem` 因需跨读 Java 题，放在 Autolab 库但由 Autolab 同步。

## 2. 02 · AI 端口

```sql
CREATE TABLE auto_ai_port (
  id                 VARCHAR(63) PRIMARY KEY,
  owner_id           VARCHAR(64) NOT NULL,
  scope              VARCHAR(16) NOT NULL COMMENT 'user|site',
  name               VARCHAR(64) NOT NULL,
  base_url           VARCHAR(2048) NOT NULL,
  api_key_cipher     TEXT NOT NULL COMMENT 'Fernet 密文',
  key_fingerprint    VARCHAR(16) NOT NULL,
  model              VARCHAR(128) NOT NULL,
  wire_api           VARCHAR(24) NOT NULL DEFAULT 'responses',
  harness            VARCHAR(24) NOT NULL DEFAULT 'codex',
  harness_version    VARCHAR(63) NOT NULL,
  reasoning_effort   VARCHAR(16) NOT NULL DEFAULT 'medium',
  max_concurrency    INTEGER NOT NULL DEFAULT 2,
  max_job_cost_usd   NUMERIC(10,4) NOT NULL DEFAULT 2,
  monthly_budget_usd NUMERIC(12,2) NOT NULL DEFAULT 0,
  is_default         TINYINT NOT NULL DEFAULT 0,
  status             VARCHAR(16) NOT NULL DEFAULT 'active',
  version            INTEGER NOT NULL DEFAULT 1,
  created_at         DATETIME(6) NOT NULL,
  updated_at         DATETIME(6) NOT NULL,
  INDEX ix_port_owner (owner_id, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 唯一默认：由应用在事务内维护（MySQL 无部分索引）
ALTER TABLE auto_task_job
  ADD COLUMN port_id VARCHAR(63) NULL,
  ADD COLUMN harness VARCHAR(24) NULL,
  ADD INDEX ix_job_port_status (port_id, status);
```

**唯一默认的并发安全**：

```sql
BEGIN;
SELECT * FROM auto_ai_port WHERE owner_id = ? FOR UPDATE;
UPDATE auto_ai_port SET is_default = 0 WHERE owner_id = ? AND is_default = 1;
UPDATE auto_ai_port SET is_default = 1 WHERE id = ? AND owner_id = ?;
COMMIT;
```

`uq_binding_ref` 即「一个比赛或题单最多绑定一份查重结果」的物理保证。

## 7. 索引与容量估算

| 表 | 预估行数 | 主要查询 | 说明 |
| --- | --- | --- | --- |
| `auto_ai_port` | 百级 | 按 owner 列 | 小 |
| `auto_agent_session` | 万级 | 按 owner+state | 定期归档 |
| `auto_agent_execution` | 十万级 | 按 job | 保留 90 天 |
| `oj_unified_problem` | 十万级 | 可见性+组 | 主检索表 |
| `oj_plagiarism_pair` | 十万级/年 | scan+similarity | 大表，注意分页 |
| `oj_exam_account` | 千级/场 | exam+candidate | 小 |

## 8. 回滚

- 新表：直接 `DROP`（无外键依赖）。
- 加列：`NULL`/默认值列可保留不删（不影响旧代码）。
- **不可回滚的点**：`oj_unified_problem` 一旦被前端依赖，回滚需同时回滚前端。因此该表上线与前端切换必须同批。
- `auto_task_job.port_id` 为 `NULL` 时行为等价于旧版本（走站点兜底端口），天然兼容。
