> 当前草案 **17 张新表、4 张既有表的 11 个新增列**。不得直接把本文整段 SQL 应用于任何数据库。实际 DDL 要按功能拆分 migration，完成 SCHEMA/AUTH/SECRETS 门禁和恢复演练后另行执行。

## 4. 必须实现的事务与状态约束

- **默认端口**：default_owner_id 只为 active 默认行非 NULL，允许多个非默认。先锁已存在的 AiAccount(subject_id) 稳定行，再执行清默认/设置/删除/CAS；零端口并发也要测。账户初始化用原幂等 account()，不能用不存在的端口行锁代替。
- **端口预算**：AiRun.port_id 只是查询维度，仍复用原逐请求预留与幂等结算；价格/端口版本写入冻结输入和 usage 元数据，不存 key。旧 NULL port_id 只能属于明确 legacy 路径，不能作为 v2 隐式站点兜底。
- **运行与授权**：session.resource_id 对应原管理资源，业务事件仍在 AiResource；execution 的 attempt 与 TaskJob 租约一致，旧 worker 不能更新新 attempt。工具 call 唯一，外部结果不确定进入 unknown，不把数据库事务当成外部事务。
- **统一题目**：manager_group_ids 是多组投影，不是新鉴权权威；visibility=NULL 为未迁移，回源保留原合法 ACL。用户名映射失败、孤儿、多组冲突先出清单，不能用一个组覆盖。source_signature 和 tombstone 支持陈旧/删除检查。
- **发布与实测**：package 正文在 AiResource，publish receipts 是分布式操作证据。trial 邀请只存 hash；v1 一邀请一人、一次兑换、一个会话，多人创建多邀请。兑换按行锁原子消耗 used_count 并写 session hash，不覆盖已存在会话；attempts 是有界追加记录或不可变产物引用，不覆盖上一份代码。package_version/manifest 变化使旧实测失效；trial.version 是独立可变 CAS。管理撤销按 package/trial 关联和 trial.version CAS 幂等写 revoked、递增 version，在原包事件留 operation_key/receipt；受限会话每次都回查邀请撤销状态，不能只在兑换时验证。
- **查重**：left/right 按源提交 ID 规范化后入库；review 使用 version CAS 与 decision_log 同事务。scan 固定 capture_metric/review_metric；当前 CLI AVG 采集供 MAX 复查时必须 floor=0，跨指标非零 floor 不可宣称完整。pair.metrics 保存报告原始数值的字符串（如 MAX/AVG），Decimal 原值用于筛选/计数/分页/发布；similarity 量化列只作展示与保守粗筛，不能丢弃量化等号候选。API 阈值最多四位小数，超精度拒绝后再入库。binding 只指向已完成人工批准的发布 manifest；重新绑定追加不可变发布对象，旧 manifest 持续可追溯，不物理删除旧历史。
- **账号**：本库 UNIQUE 不代表 OJ 无重名。导入状态、请求摘要/receipt 与冻结密码保留；unknown 先对账，不 reset 既有账号。材料用 AiResource/AiFile 保存固定 revision，不另建平行台账。
- **监考**：session_id 不是凭证，token_hash 单独唯一；expires_at 不晚于 link 有效期，link 撤销级联拒绝读取（每次验证，不靠缓存）。消耗 max_uses、动作 request_id、scope/version 校验用事务保证。

## 5. 分功能迁移与回退
